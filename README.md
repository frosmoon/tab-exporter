Tab Exporter

A simple tool for exporting browser tabs in a convenient format.

Features

Export your currently open tabs

Quickly copy or save exported tab information

Lightweight and easy to use

Installation
From source

Clone the repository:

git clone https://github.com/frosmoon/tab_exporter.git
cd tab_exporter

Install it as a Chrome Extension after having enabled 'Developer Mode' on the chrome://extension page.

Usage

Just click on the icon shows on the extension area and just click 'Export'.

For example:

Open your browser tabs.

Launch Tab Exporter.

Select the tabs you want to export.

Choose the desired export format.

Export or copy the result.
